## 维护规则

- 产品决策保留理由和范围；实现契约以共享类型、工具定义及运行时代码为准，代码变化时同步相关文档。
- 不再维护 legacy/new 双核，不保留旧记忆事实源；当前数据库直接使用统一结构，不承诺旧数据迁移。
- API / Worker、SSE、取消、任务隔离和多会话恢复是保留边界。前端退订不等于取消后台任务。
- 能力实现、mock 检查、真实数据库核验、模型语义与交互验收分开记录。
- 不把证据可追溯写成结论正确，不把有限案例写成通用准确率，不展示模型私有推理链。
- 默认只做快速非交互验证；真实服务、外部模型、浏览器 E2E 和完整回归由用户安排。
- 新记录不要复制状态到所有文档；状态写入交付页，执行结果写入验收资产，过时过程进入归档。
