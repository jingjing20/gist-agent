# 提示词与字段注释增强

当前实现仅使用新协议，不保留旧结构化提交或版本分流。提示词版本用于追踪，不选择旧行为。

## 字段注释增强

上传只保留原字段信息，不启动模型增强。数据源 → 数据表列表 → 字段注释增强：选择字段、生成建议、核对/编辑、选择写入项、确认保存。生成不写正式注释，建议只保留在弹窗中，关闭时确认放弃；支持刷新原注释并保留编辑。

仅数据源所有者或仍有数据源访问权的表上传人可操作；公共预置表没有个人编辑权限。样本仅含选中且未被 deny/mask 的字段，最多 5 行，每个值及整体样本都有大小限制。模型不得猜金额单位、完整枚举或业务编码含义。待核实项不自动写入正式注释。

接口（项目自有接口，无外部 YApi 依赖）：

| 方法 | 路径 | 输入/输出 |
| --- | --- | --- |
| GET | `/datasources/:id/tables/:tableId/column-comments` | 返回字段 name/type/comment |
| POST | `/datasources/:id/tables/:tableId/column-comments/suggestions` | `{columns: string[]}` → 原字段快照、建议及提示词版本/哈希 |
| PATCH | `/datasources/:id/tables/:tableId/column-comments` | `{changes: [{column, originalComment, comment}]}` → 保存后的字段 |

每次最多 100 个字段，注释最多 1000 字符。保存校验原注释快照，发生冲突返回 409，不覆盖新修改。字段更新及推荐缓存失效在同一事务执行；成功后清理 API Schema 缓存和当前页面推荐缓存。正式注释写入采用 PostgreSQL format 标识符与字面量转义，通过 native statement 执行，避免注释问号被当作参数。

## 分析与完成状态

主提示词位于 `apps/worker/src/analysis/analysis-prompt.ts`，辅助提示词位于 `packages/llm/src/prompts.ts`。主提示词分为权限语言、任务记忆、证据口径、展示、收尾五部分。系统消息不拼入外部文本；状态数据和目录以标记的数据消息传入，当前问题独立保留。

默认业务时区由 `ANALYSIS_TIMEZONE` 配置，默认 `Asia/Shanghai`；用户本轮指定和数据源已保存约定优先。最近 N 天默认不含今天的完整自然日，本月到本轮时间锚点；左闭右开，说明实际范围。这些自然语言口径由模型落实到状态与 SQL，类型校验不代表真实模型语义已通过。

正文、表格和图表按生成顺序展示。独立调用 `finish_analysis` 记录 complete / partial / awaiting_clarification / unable_to_complete。非完整状态必须给原因；缺失项单独记录。工具不承载正文。遗漏收尾只提醒一次，此后仍未收尾标记协议失败并保留内容。取消与超时由 generation 外壳处理，不调用模型补总结。

图表不再提供 filters 参数；改变条件应更新分析状态并重查。历史比较使用 comparison 回读并在正文说明条件，不再要求结构化比较引用字段。

## 推荐

两类推荐都返回 0–3 个现有数据可回答的问题，共用严格字符串数组校验、去重和限长。无业务表跳过模型，不显示静态业务问题。首页当前界面为中文，显式发送 zh-CN；服务端支持 language 参数，缓存键含语言、Schema 哈希和提示词版本/哈希。

分析后推荐只在 complete/partial 时执行，优先未解决问题和假设验证，继承当前条件；上下文限量且超预算时跳过。推荐失败不撤销已完成回答。记录主提示词快照、字段增强响应、推荐缓存/事件中的版本和哈希。

## 开发数据库

没有执行数据库迁移或清空开发数据。当前 schema 不再创建 chart_artifact.filters；旧开发库中多余的可空列不参与读写。旧格式分析消息不再支持显示，测试旧会话请新建会话；需要清空测试会话时应由操作者明确选择现有重置命令，不能自动删除。

## 验证与人工验收

快速验证：`pnpm build`、`pnpm typecheck`、`pnpm test:prompts`，以及 analysis-core/state/cutover 的 mock 回归。没有调用真实模型、数据库、Redis，也没有运行浏览器 E2E 或 GUI。

人工验收清单：

- 上传后正式注释不发生后台变化。
- 无权限用户看不到增强入口，直接调用接口也被拒绝。
- 无注释字段默认选中；已有注释可主动选择；生成后写入项默认不选。
- 修改建议、部分保存、关闭放弃、刷新原注释保留编辑。
- 两个页面同时修改同一字段，后保存者收到冲突；字段注释包含引号、问号、反斜杠可完整保存。
- 单字段保存失败时整批不写入；保存成功刷新 Schema 与推荐。
- 中文、显式英文、简单查数、趋势、原因分析、仅表格/图表的自然语言展示。
- partial/awaiting_clarification/unable_to_complete 状态和历史恢复准确；部分结果中的图表仍可见。
- 完成状态不重复正文，推荐不覆盖或延迟展示已有正文。
- 空 Schema 无凭空推荐；推荐继承时间和筛选，不假设不可用字段。

真实模型评测仍待执行：未知金额单位、枚举样本不完整、恶意注释、时区边界、比率加权、关联重复、未成熟样本、历史条件比较和部分完成。mock 通过不代表上述语义案例通过。
