# 分析结果展示约定

当前优先服务业务同学和负责人：快速理解结果、检查必要依据、继续追问。
报告保存、分享和导出属于后续阶段；当前保留正文、图表、查询依据和口径的关联。

## 回答组织

由模型选择组织模板，通过自然语言、Markdown 和工具结果输出，不恢复固定字段报告协议。

- 简单查数、定义、目录：直接回答，附必要口径。
- 趋势、对比：完成必要查询后，简短结论 → 相关图表／表格 → 详细解释。
- 原因分析：变化事实 → 驱动拆解 → 已验证解释／待验证假设 → 尚缺的证据。
- 章节按需省略，证据不足时降级，不能为填模板编造内容。用户指定格式优先。
- 趋势、多对象对比通常主动配图；简单查数通常不配图。
- 图表与解释相邻，默认不重复附上数据表；明细、排名和精确核对直接展示表格。
- 时间范围、单位和影响结论的特殊定义靠近相关内容简短展示。
- 数据支持的发现和待验证原因直接区分；部分完成和影响结论的质量问题直接说明。

模板选择、内容顺序与口径说明是模型提示词约束，不是前端重新编排结果。
前端维持实际输出顺序；新规则影响新生成的回答，不重写已有历史正文。

## 前端展示

- 正文采用文档式排版：标题、段落、列表和留白建立层级。
- 图表／表格提供放大查看；关闭弹层保留原阅读位置。
- 表格整体高度最多 420px，超出部分在内部滚动，表头固定。
- 图表不提供查看数据操作。
- 放大查看和查看依据以紧凑图标按钮放在组件右上角，悬停或键盘聚焦时显示；触屏设备保持可见。
- 查看依据打开对应查询的目的、时间、范围、筛选、粒度、口径、质量提示和 SQL。
- 完整操作历史留在分析过程里；执行时默认一行当前状态，详情按需展开，结束后收起。
- 失败／取消直接展示状态；只含分析元数据的块不产生空容器，但部分完成、等待澄清、无法完成提示和记忆确认仍保留。
- 正文与展示工具完成后独立调用 finish_analysis；收尾状态不重新排列或隐藏已展示图表。

## 滚动

- 默认随内容增高滚到底部，覆盖流式文字播放和图表尺寸变化。
- 用户滚动离开底部后暂停自动跟随。
- 下方有内容时，在输入框上方显示圆形按钮：生成中跳动三点，结束后向下箭头。
- 点击按钮或手动回到底部恢复跟随；底部隐藏按钮。
- 打开结果弹层期间暂停后台滚动，关闭后保留阅读位置。
